# 🦝 TrashDash

**TrashDash** is a fun and addictive 2D side-scrolling game created using **Adobe Animate** and **HTML5 Canvas**. Inspired by the mechanics of *Flappy Bird*, you control a mischievous raccoon who dodges obstacles, collects trash treasures, and dashes through a vibrant animated world.

🎮 **[Play the game live here!](https://eshab01.github.io/TrashDash-Animation/)**

## 🎮 Gameplay

- Tap/Click or press **Spacebar** to make the raccoon jump.
- Avoid obstacles like trash cans and fences.
- Collect bonus items for extra points.
- Try to beat your high score!

## 📦 Features

- 🎨 Hand-drawn animations and visuals made in Adobe Animate
- 📜 Smooth HTML5 Canvas rendering
- 🧠 Simple yet challenging gameplay
- 💥 Sound effects and animations for immersive experience
- 🔁 Endless level generation

## 🚀 Getting Started

1. Clone or download the repository.
2. Open `index.html` in your browser.
3. Start jumping and help the raccoon collect trash!

```bash
git clone https://github.com/Eshab01/TrashDash-Animation.git
cd TrashDash-Animation
start index.html
```

> **Note:** Make sure all the assets (images, sounds, JS files) are in the correct directory as used in the Animate export.

## 🛠 Built With

- **Adobe Animate** – for animation and asset design
- **HTML5 Canvas** – for rendering the game
- **JavaScript** – for game logic and interactions
